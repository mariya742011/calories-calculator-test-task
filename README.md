# Calories Calculator — UX/UI Design Test Task

# Overview

Calories Calculator is a mobile app design concept that helps users calculate the calorie content of individual food products and homemade dishes, as well as discover recipes that fit their calorie preferences.

The project focuses on creating a clear, intuitive, and consistent user experience, from product discovery and UX architecture to visual design and interactive prototyping.

# Project Goals

* Make calorie calculations for individual food products simple and intuitive.
* Allow users to calculate the calorie content of homemade dishes by combining ingredients.
* Help users discover recipes based on a selected calorie budget.
* Create a cohesive visual experience supported by a reusable design system.

## Core User Flows

### Calculate Calories

Users can search for a food product, adjust its quantity, and view its nutritional information. They can also combine ingredients to calculate the calorie content of a homemade dish.

### Discover Recipes

Users can explore recipes, review their nutritional information, and find options that fit a selected calorie budget.

## Design Principles

* **Clarity:** Present nutritional information in an easy-to-understand format.
* **Consistency:** Use reusable components and design tokens across screens.
* **Usability:** Keep the main actions accessible and the core flows straightforward.
* **Transparency:** Communicate nutritional information and data sources clearly.
